## [0.0.7] — 2026-10-05

### Added

#### Batch de generación IA (Propuesta)

- **`PropuestaBatchController`** con endpoint orquestador:
  - `GET /api/propuesta/{id}/generar-todo` — genera las 6 secciones en secuencia, con `set_time_limit(600)` para no morir en timeout.
  - Devuelve resumen consolidado: `todas_ok`, `total_s`, y por cada sección `ok`, `proveedor`, `modelo`, `tiempo_ms`, `error`, `texto_len`, `duracion_s`.
  - Continúa con las demás secciones aunque una falle (no detiene el batch).
  - Log de excepciones por sección (`Batch · excepción en sección`).
- **`PropuestaController::guardarSeccion()`** nuevo:
  - Persiste cada sección en `storage/app/expedientes/{id}/propuesta/{seccion}.json`.
  - Formato: `{ ok, texto, proveedor, modelo, tiempo_ms, generado_en }`.
  - Un archivo por sección → sin race conditions si se generan en paralelo.
  - Crea la carpeta `propuesta/` si no existe.

#### Inyección al `.docx`

- **`PropuestaWordController`** implementado (hereda de `WordController`):
  - `plantilla()` → `plantillas/1.PROPUESTA.docx`.
  - `nombreArchivo()` → `propuesta_{id}`.
  - `construir()` inyecta:
    - `EMPRESA_BRINDA`, `EMPRESA_RECIBE`, `FECHA`, `NOMBRE_PROGRAMA` desde `ia.json` / `data.json` / `meta.json`.
    - `TEXTO_PROPUESTA`, `INTRODUCCION`, `PROBLEMATICA`, `OBJETIVO_GENERAL`, `OBJETIVOS_ESPECIFICOS`, `METODOLOGIA` desde los JSON por sección.
  - Endpoint: `GET /api/propuesta/{id}/word` — descarga el `.docx` final.
- **Helpers de inyección respetando el formato del Word**:
  - `inyectarBloque()` → `setComplexBlock` con `TextRun` + `addTextBreak()` para respetar `\n` dentro de celdas de tabla.
  - `inyectarLista()` → separa objetivos específicos en párrafos por línea.
  - `inyectarConNegritas()` → parsea `**SUBTÍTULO.**` a runs con `bold=true`, limpia asteriscos sueltos.
- **`limpiar()`** en `PropuestaWordController`:
  - Quita comillas envolventes.
  - Normaliza saltos (`\r\n`, `\r` → `\n`).
  - Colapsa 3+ saltos seguidos a 2.
- **`esc()`** para escapar XML de Word (`htmlspecialchars` con `ENT_QUOTES | ENT_XML1`).
- **`formatearFecha()`** con `Carbon` (fallback al string original si falla el parse).

#### Extracción de metadatos

- **`WordController` abstracto** extendido con propiedad `protected string $expedienteId = ''`, seteada en `export()` antes de llamar a `construir()`. Permite que los hijos accedan al `$id` sin cambiar la firma del método abstracto.

### Changed

- **`PropuestaController::generarSeccion()`**: se agrega el guardado en disco (vía `guardarSeccion()`) antes del `return`. El `$payload` se construye a partir de `$resultado` y se pasa al método.
- **`PropuestaWordController::construir()`**: eliminados los vestigios del borrador (`extraerIdDelTemplate()`, comentarios obsoletos). El `$id` se toma directo de `$this->expedienteId`.

### Fixed

- **`Undefined variable $resultado`** en `PropuestaController::guardarSeccion()`: el método recibía `$payload` pero intentaba usar `$resultado` (variable fuera de scope). Corregido usando `$payload[...]` con defaults (`?? false`, `?? ''`, `?? null`).
- **`Call to undefined method PropuestaWordController::extraerIdDelTemplate()`**: eliminada la llamada al método fantasma que nunca existió (vestigio del borrador inicial).
- **Nombres de modelo resueltos**: `gemini-2.5-flash` (o el configurado en `.env`) — ya no se llama a modelos inexistentes (`gemini-3.5-flash`).
