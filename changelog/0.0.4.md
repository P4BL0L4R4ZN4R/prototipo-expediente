## [0.0.4] — 2026-10-05

### Added

#### Backend (Laravel)

- **Controller `ResumenWordController`** en `App\Http\Controllers\Word`:
  - `GET /api/prototipo/excel/word/resumen/{id}` — genera y descarga el `.docx` del Resumen Ejecutivo a partir de la plantilla `plantillas/6.RESUMEN-EJECUTIVO.docx`.
  - `construir()` — reemplaza los placeholders escalares (`EMPRESA_BRINDA`, `EMPRESA_RECIBE`, `TITULO_1`, `OBJETIVO`, `CIUDAD`, `FECHA_INICIO`, `FECHA_FIN`) e inyecta la lista de procesos con `cloneBlock`.
  - `listaProcesos()` — transforma `$ia['conceptos']` en un array de reemplazos y clona el bloque `${LISTA_PROCESOS}` con `cloneBlock('LISTA_PROCESOS', 0, true, false, $replacements)`, respetando el formato de lista numerada definido en la plantilla.
  - `formatearFecha()` — convierte `YYYY-MM-DD` a formato español (`"8 de noviembre del 2024"`).

- **Plantilla `6.RESUMEN-EJECUTIVO.docx`** en `storage/app/plantillas/`:
  - Placeholders escalares: `${EMPRESA_BRINDA}`, `${EMPRESA_RECIBE}`, `${TITULO_1}`, `${OBJETIVO}`, `${CIUDAD}`, `${FECHA_INICIO}`, `${FECHA_FIN}`.
  - Bloque de lista: `${LISTA_PROCESOS}` / `${item_proceso}` / `${/LISTA_PROCESOS}`. La línea `${item_proceso}` tiene formato de lista numerada aplicado en Word, por lo que cada clon respeta el formato.
  - Se abandonó `${CONCEPTOS_DESARROLLADOS}` como placeholder único (no soportaba listas).

- **Log de diagnóstico temporal** en `WordController::export()`:
  - Registra `id`, `clase`, `plantilla`, `ia` y `data` recibidos antes de construir el Word. Útil para verificar qué llega al generador.

#### Rutas nuevas en `routes/api.php` (grupo `prototipo/excel`)

- `GET /word/resumen/{id}` → `ResumenWordController@export`.

#### Documentación de diagnóstico

- Se determinó que **`cloneRowAndSetValues` no sirve para listas**: solo funciona sobre filas de tabla (`<w:tr>`). En párrafos genera `Can not find the start position of the row to clone`.
- Se determinó que **`setComplexValue` con `ListItemRun`** corrompe el `.docx` porque `TemplateProcessor` reemplaza por defecto bloques `w:r`, no `w:p` (donde viven las listas).
- **Patrón correcto confirmado**: `${bloque}` + `${item}` con formato de lista + `${/bloque}` + `cloneBlock()`.

### Changed

- **`WordController` (base)**:
  - Se agregó un log temporal (`WORD · datos recibidos`) para diagnóstico del flujo de datos hacia los hijos. **Pendiente remover o condicionar a `app()->environment('local')`.**

- **`ResumenWordController` (iteraciones descartadas)**:
  - Se intentó primero `setComplexBlock` con `TextRun` + `addText` + `•` manual (funciona pero sin lista nativa).
  - Se intentó `setComplexValue` con `CustomTemplateProcessor` heredado (falla por `getXmlWriter()` no expuesto).
  - Se intentó `cloneRowAndSetValues` sobre `${ITEM_PROCESO}` (falla porque no es fila de tabla).
  - **Solución final**: `cloneBlock` sobre `${LISTA_PROCESOS}` con `${item_proceso}` formateado como lista en Word.

### Fixed

- **`Can not clone row, template variable not found or variable contains markup`**: causado porque `${ITEM_PROCESO}` estaba en un párrafo, no en una tabla. Se cambió el enfoque a `cloneBlock`.

- **`Can not find the start position of the row to clone`**: mismo origen que el anterior, `cloneRow` no encuentra `<w:tr>`. Descartado `cloneRow` para listas.

- **`Call to undefined method CustomTemplateProcessor::getXmlWriter()`**: `TemplateProcessor` de PHPWord no expone `getXmlWriter()` en la versión instalada. Se abandonó el enfoque de heredar la clase.

- **`Cannot add ListItem in TextRun`**: `TextRun` no es un contenedor válido para `ListItem`; solo `Section`, `Header`, `Footer`, `Cell` y `Footnote` lo son. Se descartó esa ruta.

- **`BadMethodCallException` en `AbstractContainer`**: derivado del intento de meter `ListItem` en `TextRun`.

### Removed

- **`CustomTemplateProcessor`** (clase heredada dentro de `ResumenWordController`): eliminada tras confirmar que `getXmlWriter()` no está disponible.

- **`use PhpOffice\PhpWord\Element\ListItemRun`**, **`use PhpOffice\PhpWord\Style\ListItem`**, **`use PhpOffice\PhpWord\Shared\XMLWriter`**, **`use PhpOffice\PhpWord\Writer\Word2007\Element\Container`** del `ResumenWordController`: imports sin uso tras las iteraciones descartadas.

- **Numeración manual `($i + 1) . '. '` en `TextRun`**: descartada como solución "parche", ya que no es una lista nativa de Word.

### Notes

- **Regla aplicada**: los Word controllers solo pintan. Los datos vienen de `ia.json` y `data.json` sin transformación en el controller.
- **Regla aplicada**: la plantilla `.docx` controla el formato (listas, tablas, estilos). El código solo inyecta datos.
- **Regla aplicada**: cuando un formato de Word es complicado (`vMerge`, listas numeradas), se prefiere que la plantilla lo defina con su formato nativo y el código use `cloneBlock` / `setComplexBlock` apropiadamente.
- **`cloneRow` es exclusivo para tablas**. Para listas o párrafos repetidos usar `cloneBlock`.
- **Bug pendiente heredado de 0.0.1**: `FixedData.php` sigue extrayendo `fecha_inicio` como `"Fecha de Termino:"` y `fecha_termino` como `null`. Detectado durante el log de diagnóstico del Resumen. Afecta a la fecha mostrada en el Word (`${FECHA_INICIO}` sale con texto de etiqueta, `${FECHA_FIN}` sale vacío).
